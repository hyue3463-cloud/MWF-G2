# Xu Zihao - UV Index Analysis

This branch contains my part of the Malaysia Weather Forecast group project.

## Research question

Which weather conditions correspond to the highest UV index values, and at what threshold should public UV warnings be issued?

## Files

- `xu_zihao_uv_index_analysis.ipynb`: my analysis notebook for the UV index question.
- `data/malaysia_weather_cleaned.csv`: cleaned dataset used by the notebook.
- `metadata.json`: dataset file information and column list.

## Main conclusion

High UV index values are mainly associated with daytime observations, especially around midday and early afternoon. Temperature tends to be higher under high-UV observations, while rainfall is usually low. For public communication, a UV warning should be issued from **UV Index 6 and above**, with stronger alerts for **UV Index 8+** and **UV Index 11+**.
